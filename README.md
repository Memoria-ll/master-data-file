# master-data-file

アークナイツに関する各種データを公開するリポジトリです。

## データについて

### master

`master` 配下のデータは、各種Wiki等の公開情報を参照し、手動で整理・作成しています。

### stage

`stage` 配下のデータは、[Penguin Statistics](https://penguin-stats.io/) のデータをもとに、毎日6時頃に取得・更新しています。

### statistics

`statistics` 配下のデータは、[明日方舟一图流](https://ark.yituliu.cn/) のデータをもとに、毎日6時頃に取得・更新しています。

取得元のデータにライセンスまたは利用条件が定められている場合は、それらの条件が優先されます。

## 利用について

このリポジトリで公開しているデータは、アプリケーションやツール等から参照して利用できます。

ただし、`stage` および `statistics` 配下のデータについて、このリポジトリから取得したデータそのもの、または実質的に同一のデータセットを、別のデータ配布元・ミラー・API等として再公開・再配布することは禁止します。

この制限は、それぞれの取得元から利用者自身が直接取得したデータの利用を制限するものではありません。取得元の利用条件に従ってください。
